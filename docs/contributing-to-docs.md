# Contributing to Documentation

Clear documentation is just as important as reliable code. Accurate guides and
specifications ensure that everyone can understand, use, and succeed with the
zigocracy toolchain.

You do not need to install any compilers or developer tools to help. All of
our documentation lives in plain-text Markdown (`.md`) files, allowing you to
contribute changes directly using a text editor or the GitHub web interface.
